Entrance Music

    Entrance Music system and music implemented by RetroRandyPrice
    Themes are assigned per-attire. Some characters have multiple theme songs depending on which costume you select.

Arenas

    6 new arenas: Thunder, Clash of Champions, Fall Brawl, World War 3, Spring Stampede, and nWo Nitro
    Starrcade 97 updated to Starrcade 98
    Updated Turnbuckle Textures & Polygons for every arena.
    Nitro now has era accuratered turnbuckle pads

Championship Mode

    After unlocking a championship, you will no longer have to complete a gauntlet to compete for a title. After the belt is unlocked, you can challenge for it directly from the Championship menu.
    Champions now wear their title belts for entrances in exhibition mode.
    Triple Crown Support: champions can wear up to 3 championship belts at a time.
    As a result of these feature changes, the Unlock All code can crash your game if you use it and enter a title match. .

    Removed Manager from Wrath costumes 2-4 (Wrath 98)

Bugfixes

    Fixed bug that prevented some of the added wrestlers' apperance and name edits from saving. All wrestlers now fully editable + savable
    Fixed bug with several characters that resulted in invalid chops/floating when attempting elbow drops from the ring apron
    Fixed bugs with several custom/ported moves that resulted in characters warping into the ring if moves were performed at ringside on floor
    Fixed issue with several characters climbing the turnbuckle the wrong way before performing diving moves.
    Fixed bug that prevented opponents from tapping out to Lex Luger's Torture Rack Special
    Fixed bug with British Bulldog's stolen finisher
    Fixed bug with Disco Inferno's Last Dance ground submission
    Fixed bug with Rick Rude's grapple to opponents on the top rope
    Fixed issue that caused some textures to display incorrectly on original hardware
    Fixed stutter, lag and clipping present during the intro sequence
    Fixed other various gameplay bugs that were reported
